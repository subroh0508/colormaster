# i18n (compose-multiplatform-resources) 運用

> **5 行以内 summary**: ColorMaster の i18n は compose-multiplatform-resources を採用
> (ADR 0006)。旧 `public/locale/` の文言は C4 (EPIC-002) で移植。
> 本ファイルは文言 ID 命名規約 / locale 追加手順 / 翻訳更新フロー を記述。
> 本格化は C4 で実施。

## 文言 ID 命名規約 (C4 で本格化)

- 形式: `<feature>_<category>_<key>` (例: `home_title`, `search_filter_brand_label`)
- スネークケース、英小文字、最大 3 階層
- 機能横断の共通文言は `common_*` プレフィックス

## ディレクトリ構造 (C4 で本格化)

```
composeApp/src/commonMain/composeResources/
  values/strings.xml      (デフォルト: ja)
  values-en/strings.xml   (英語)
  ...
```

## locale 追加手順 (骨格)

1. `composeResources/values-<locale>/strings.xml` を作成
2. デフォルト (ja) の全キーを翻訳
3. `./gradlew check` で missing translation を検出 (A6 で機械化)

## 翻訳更新フロー

- 新規文言追加時は **全 locale を同時に追加** (PR レビューで CI が missing を検出)
- 翻訳のみ更新する PR は `chore(i18n): update <locale> translations` でコミット
